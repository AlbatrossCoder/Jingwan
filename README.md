## 下载

请到 [Releases](https://github.com/AlbatrossCoder/Jingwan/releases) 下载最新 APK，例如：

`Jingwan_0.2.3_release.apk`

安装前可核对立面的 SHA256（若该版本附有校验文件）。

## 安装（Android）

1. 允许本机安装「未知来源」应用（设置路径因品牌而异，一般在安全 / 应用管理里）。
2. 打开下载的 APK 安装。包名：`app.dswhale`。
3. 若曾安装过旧包，可用同一签名覆盖安装；换签名则需先卸载（本地数据会清空）。

## 使用前准备

- 需要自行准备大模型 **API Key**（应用内「接入」填写；密钥保存在本机，不经过鲸湾服务器）。
- 选定人物后即可聊天；换人需先清空本地数据（不可恢复），接入密钥会保留。

## 隐私要点

- 对话与记忆优先存在本机。
- 网络请求指向你配置的模型服务商；本发布仓不托管你的密钥或聊天内容。
